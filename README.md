# Universal Video Downloader

A simple and powerful Python script to download videos from various platforms across the internet using `yt-dlp`.

## Features
- Supports hundreds of video sites (YouTube, Vimeo, Twitter, etc.).
- Downloads the best available quality.
- Easy to use via command line.

## Prerequisites
- Python 3.x
- `yt-dlp` library

## Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/Zezo998/universal-video-downloader.git
   cd universal-video-downloader
   ```
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
Run the script with the video URL as an argument:
```bash
python3 downloader.py "YOUR_VIDEO_URL_HERE"
```
